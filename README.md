# Hi, I'm Mykyta

I build small Python projects around questions that can be answered with data. I like taking a messy input, turning it into a clear comparison, and showing how the result was calculated.

### Featured project

**[Lithuania Flight Planner](https://github.com/privateAML/lithuania-trip-planner)** compares flights from Vilnius, Kaunas and Palanga by price and travel time. Python collects and standardizes the offers, and SQL ranks them. The app also lets a group compare individual itineraries and see their total airfare.

The project README walks through a London search with two charts and the underlying fare snapshot. In that example, an extra €5 bought a flight that took 25 minutes less.

**Tools used in the project:** Python, SQL, SQLite and Tkinter.
