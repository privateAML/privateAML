# Hi, I'm Mykyta

I build Python projects around questions that can be answered with data. I enjoy deciding what to measure, making comparisons fair, and explaining the trade-offs in plain English.

## Featured project

**[Lithuania Flight Planner](https://github.com/privateAML/lithuania-trip-planner)** compares European flights from three Lithuanian airports by price and travel time. It also lets groups compare individual itineraries and see their total airfare.

The README includes two charts from a real search. In that snapshot, paying €5 more bought a flight that took 25 minutes less.
